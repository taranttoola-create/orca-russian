## Решённые проблемы (важно понимать при будущих правках)

### 1. Ошибка установки «Plugin installation failed» (v1.2.0)

**Симптом:** плагин не ставился, интерфейс показывал общее «Plugin installation failed.
Check the source and try again.» без деталей.

**Причина:** начиная с Orca 1.4.196 префикс `orca-` в id плагина зарезервирован за
официальными плагинами stablyai — они обязаны ставиться только из `github.com/stablyai/*`.
Наш id был `orca-russian`, репозиторий — `taranttoola-create/orca-russian`. Orca отклоняла
установку ошибкой `reserved plugin identity ... must resolve to the stablyai organization`,
но UI показывал её как общую.

**Решение:** id переименован в `russian`. **Не начинать id с `orca-`.**

### 2. Интерфейс не переключился на русский (после v1.2.0)

**Причина:** настройка `uiLanguage` хранила старый id (`plugin:taranttoola-create.orca-russian/ru`),
которого после переименования не стало.

**Решение:** заново выбрать язык в Settings → Appearance → Language. В README добавлен
блок-предупреждение.

### 3. Дрейф плейсхолдеров (исправлено в v1.3.0)

Две строки потеряли подстановки и **уже попали в релиз**: `screenshotsHint` потеряла
`{{count}}` и `{{maxSize}}`, `structuredSessionLaunchFailed` потеряла `{{value0}}`. Орка
такие строки принимает, но отображает их криво. Вывод: **всегда сверять плейсхолдеры
автоматически** (`tools/validate-catalog.mjs` это делает).

### 4. Значения > 8192 символов (найдено в v1.3.0)

В Orca 1.4.212 при добавлении новых строк валидатор упал на `...visual.ship.styles.*`
(9965 символов). Это сырые CSS-блобы, они лежат в `en.json` как обычные строки. Если
включить их в каталог — **весь каталог отклоняется**. Решение: не включать значения > 8192.
Таких в Orca ровно два, оба CSS.

## Как создавался перевод (исторически)

1. Каталог Orca (`en.json`) извлекался из распакованного `app.asar` или из тега репозитория.
2. Считался diff: чего нет в нашем `ru.json`.
3. Недостающее переводилось **батчами через субагентов** (по ~120 строк), с жёсткими правилами:
   не трогать плейсхолдеры, не переводить продуктовые имена, соблюдать глоссарий.
4. Батчи сливались, проверялись плейсхолдеры, устаревшее удалялось.
5. Прогонялся валидатор Orca (`plugin-language-pack-artifact.js`).
6. Версия поднималась, тег ставился, пуш в оба зеркала.

> Внимание: параллельный запуск многих субагентов упирался в лимиты API. Надёжнее
> последовательно, по одному.

## Что осталось нерешённым

- **Названия сочетаний клавиш** — не переводятся (хардкод в приложении). Issue #25048, ждём.
- **Плюрали** — Orca поддерживает 2 формы из нужных 4. Чинится только в Orca (PR #12505).
- **Маркетплейс** — наш PR #9 висит без ревью, как и все остальные community-PR.
- **Обратная связь от разработчиков** — почти отсутствует в GitHub; живой канал — Discord.

Подробности по каждому — в соседних файлах (`UPSTREAM.md`, `KNOWLEDGE.md`).
