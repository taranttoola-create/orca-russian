# Changelog

## 1.3.0 — 2026-09-26

- Совместимость с Orca **1.4.212**: переведены **966 новых строк** (каталог Orca вырос до 14 733 ключей), удалены 93 устаревших ключа.
- Основные новые разделы: возобновление чатов после перезапуска (`NativeChatResume*`), боковая вкладка Agents, история и поиск сессий, статистика, редактор промптов, обновлённые настройки.
- Итог: **14 551 запись** в `locales/ru.json`; каталог прошёл валидатор языковых пакетов Orca 1.4.212 (16 380 записей с учётом вложенности).
- 180 защищённых путей `auto.components.settings.Plugin*` намеренно не переводятся (из них 34 разрешённых «chrome»-пути переведены, как и раньше).

## 1.2.0 — 2026-09-07

- **Переименован id плагина: `orca-russian` → `russian`** (ключ `taranttoola-create.russian`).
  Начиная с Orca **1.4.196** префикс `orca-` зарезервирован за официальными плагинами
  `stablyai` (устанавливаются только из `github.com/stablyai/*`), поэтому установка версий
  1.1.x на новых Orca завершалась ошибкой «Plugin installation failed. Check the source
  and try again.». С новым id плагин устанавливается из любого зеркала.
- Если стояла версия 1.1.x — удалите её в Settings → Plugins и поставьте 1.2.0 заново,
  после чего повторно выберите язык в Settings → Appearance → Language.

## 1.1.2 — 2026-09-02

- Совместимость с Orca **1.4.195+**; минимальная версия поднята до **1.4.169** (список разрешённых плагинных путей появился только в 1.4.169 — на более старых версиях каталог молча отклонялся).
- Добавлены 142 поисковых ключа настроек (категория C из [обсуждения](https://github.com/stablyai/orca/issues/17913) — спасибо @imgusev): поиск по настройкам теперь понимает русские слова, английские продолжают работать.
