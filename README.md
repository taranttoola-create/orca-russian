# Русский язык для Orca 🇷🇺

Плагин-языковой пакет, который переводит интерфейс [Orca](https://github.com/stablyai/orca) — оркестратора AI-агентов для программирования — на русский язык.

Покрывает **~13 700 строк** интерфейса: меню, настройки, палитры, дашборд, вкладки worktree, диалоги, браузер, терминал, onboarding-подсказки и остальной UI. Поиск по настройкам понимает русские слова.

## Установка

**Требования:** Orca 1.4.169 или новее.

| Версия плагина | Для какой версии Orca | Что нового |
| -------------- | ---------------------- | ---------- |
| **1.2.0** (актуальная) | **1.4.169+**, включая 1.4.196+ | новый id `russian` — версия 1.1.x не ставится на Orca 1.4.196+ (префикс `orca-` зарезервирован за stablyai); при переходе с 1.1.x переустановите плагин и выберите язык заново |
| 1.1.2 | 1.4.169–1.4.195 | русский поиск по настройкам (+142 ключа); на Orca 1.4.196+ **не устанавливается** — используйте 1.2.0 |
| 1.1.1 | 1.4.195 | +46 новых строк (SSH-диалог, статусы хоста, аннотации браузера, проверки PR) |
| 1.1.0 | 1.4.192–1.4.194 | полный перевод ~13 500 строк |
| 1.0.0 | 1.4.192 | первая версия (~90 строк) |

Плагин работает и на более новых версиях Orca: строки, которых нет в словаре, просто останутся на английском — обновление перевода выходит следом за крупными обновлениями Orca (см. [CHANGELOG](CHANGELOG.md)).

> ⚠️ **Частые ошибки при установке:**
>
> - **«Could not add this marketplace»** — вы нажали *Manage Sources*. Это для маркетплейсов (каталогов плагинов), а не для одиночных плагинов. Закройте это окно и используйте **Install plugin**.
> - **«Add an explicit #ref»** — вы вставили ссылку без тега версии. Orca требует пиннинг: добавьте `#v1.2.0` в конец ссылки, например `https://github.com/taranttoola-create/orca-russian#v1.2.0`.
> - **«Plugin installation failed. Check the source and try again.»** на Orca 1.4.196+ — вы ставите версию 1.1.x со старым id `orca-russian`: префикс `orca-` зарезервирован за официальными плагинами stablyai. Ставьте **1.2.0+** (ссылки ниже уже с нужным тегом).

### Способ 1 — из Git-репозитория (рекомендуется)

Репозиторий доступен на двух зеркалах — используйте любое:

| Зеркало | Ссылка для установки |
| ------- | -------------------- |
| GitVerse | `https://gitverse.ru/buheirf/orca-russian#v1.2.0` |
| GitHub   | `https://github.com/taranttoola-create/orca-russian#v1.2.0` |

1. Скопируйте ссылку с версией (см. таблицу выше).
2. В Orca откройте **Settings → Plugins → Install plugin**.
3. Перейдите на вкладку **Git URL**, вставьте ссылку и нажмите **Install**.
4. Просмотрите разрешения и подтвердите установку.
5. Выберите язык: **Settings → Appearance → Language → «Русский язык для Orca»** — без этого шага интерфейс останется английским (см. блок 🔤 ниже).

### Способ 2 — из локальной папки

1. Скачайте и распакуйте этот репозиторий (Code → Download ZIP).
2. В Orca откройте **Settings → Plugins → Install plugin**.
3. На вкладке **Local folder** укажите путь к распакованной папке (где лежит `orca-plugin.json`) и нажмите **Install**.
4. Подтвердите разрешения и выберите язык, как описано ниже.

> 🔤 **Обязательно после установки:** зайдите в **Settings → Appearance → Language** и выберите **«Русский язык для Orca»**.
> Интерфейс сам не переключится — плагин лишь добавляет русский язык в этот список.
> При переходе с версии 1.1.x выбор языка сбрасывается (id плагина изменился) — просто выберите его заново, без перезапуска Orca.

После установки плагин можно включать/выключать и удалять в **Settings → Plugins**. Никакой код плагина не исполняется — пакет содержит только файл перевода.

## Что переводится

| Область интерфейса            | Статус      |
| ----------------------------- | ----------- |
| Меню приложения, трей         | ✅ полностью |
| Настройки (все разделы)       | ✅ полностью |
| Палитры, дашборд, вкладки     | ✅ полностью |
| Терминал, браузер, редактор   | ✅ полностью |
| Подсказки и onboarding        | ✅ полностью |
| Диалоги доверия плагинов      | ⛔ не переводятся намеренно¹ |

¹ Технические строки (URL, команды, имена файлов) оставлены на английском языке как есть. Диалоги доверия плагинов Orca запрещает переводить через плагины из соображений безопасности — эти тексты Orca намеренно защищает от подмены.

## Обновление при выходе новых версий Orca

В новых версиях Orca могут появляться непереведённые строки — они автоматически останутся на английском (просто не будут найдены в каталоге). Перевод обновляется добавлением новых ключей в `locales/ru.json`.

Если хотите помочь с переводом — правила, глоссарий и процесс описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Формат языкового пакета

Файл `locales/ru.json` — это JSON-дерево «пространство имён → ключ → перевод», повторяющее структуру встроенных локализаций Orca. Ограничения каталога (проверяются при загрузке):

- не более 20 000 записей и глубины вложенности 16;
- значение — строка не длиннее 8192 символов;
- ключи без точек и управляющих символов;
- пути вида `auto.components.settings.Plugin*` защищены и игнорируются (кроме разрешённого «chrome»-списка).
