# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка         |
| ------ | ----------------- |
| 1.1.x  | ✅ активная       |
| < 1.1  | ❌ не поддерживается |

## Сообщение об уязвимости

Плагин не содержит исполняемого кода: только манифест `orca-plugin.json` и файл перевода `locales/ru.json`. Поверхность атаки минимальна, но если вы обнаружили проблему — сообщите об этом.

1. **Не создавайте публичный issue** с деталями уязвимости.
2. Напишите privately владельцу репозитория через личные сообщения GitVerse/GitHub или на почту профиля.
3. Включите описание проблемы, шаги воспроизведения и влияние.

Ответ — в течение 72 часов. Мы попросим минимум 90 дней на устранение до публичного раскрытия.

## Что НЕ считается уязвимостью

- Неточности перевода (создавайте обычный issue).
- Проблемы безопасности самого Orca — сообщайте напрямую в [stablyai/orca](https://github.com/stablyai/orca).
- Проблемы платформ GitVerse/GitHub.
