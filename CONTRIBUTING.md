# Как внести вклад

Спасибо за интерес к русской локализации Orca! Любая помощь приветствуется: неточности перевода, непереведённые строки после обновлений Orca, опечатки и предложения по терминологии.

## Способы помочь

- **Сообщить о проблеме** — [создайте issue](https://gitverse.ru/buheirf/orca-russian/issues) с описанием: где встретили строку, как выглядит сейчас и как должно быть.
- **Предложить перевод** — откройте pull request с правками (инструкция ниже).
- **Дополнить перевод после обновления Orca** — при выходе новой версии Orca часть интерфейса может остаться на английском: новые строки нужно добавить в `locales/ru.json`.

## Правила перевода

1. **Плейсхолдеры не трогаем.** Конструкции вида `{{value0}}`, `{{count}}`, `{{name}}` сохраняются буквально — иначе строка сломается в интерфейсе.
2. **Технические строки не переводим:** URL, пути, команды, имена файлов, сочетания клавиш (⌘⌥⇧, Ctrl+K), идентификаторы.
3. **Продукты не переводим:** Orca, GitHub, Claude, Codex, Cursor, macOS и т.п.
4. **Единый глоссарий:**

   | Термин     | Перевод            |
   | ---------- | ------------------ |
   | worktree   | worktree           |
   | workspace  | рабочая область    |
   | agent      | агент              |
   | session    | сессия             |
   | snapshot   | снимок             |
   | plugin     | плагин             |
   | marketplace| маркетплейс        |
   | commit     | коммит             |
   | diff       | дифф               |
   | branch     | ветка              |
   | repo       | репозиторий        |

5. **Стиль:** краткий UI-русский, инфинитивы для команд («Проверить обновления»). Точка в конце — только если она есть в английском оригинале.

## Ограничения формата (проверяются при загрузке плагина)

- значения — строки не длиннее 8192 символов;
- не более 20 000 записей, глубина вложенности — до 16;
- ключи не содержат точек и управляющих символов;
- пути вида `auto.components.settings.Plugin*` защищены Orca и не переводятся (кроме разрешённого списка).

## Как открыть pull request

```bash
git clone https://gitverse.ru/buheirf/orca-russian.git
cd orca-russian
# правки в locales/ru.json ...
git checkout -b fix/typos
git commit -am "Исправление опечаток в разделе настроек"
git push -u origin fix/typos
```

Затем откройте pull request в веб-интерфейсе и опишите, что изменено и почему.

## Проверка перед отправкой

Убедитесь, что `locales/ru.json` — валидный JSON:

```bash
python3 -m json.tool locales/ru.json > /dev/null && echo OK
```

## Сборка новой версии (для мейнтейнеров)

1. Внесите правки в `locales/ru.json`.
2. Поднимите `version` в `orca-plugin.json` и добавьте запись в `CHANGELOG.md`.
3. Закоммитьте, поставьте тег (`git tag v1.3.3`) и запушьте с тегом во все зеркала.
